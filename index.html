How to use Easy

Everything you need for a one-time prospect check.

Two ways to work

Use Database + Metrics when you want to compare prospects with your own status database. Use Metrics only when you only need to evaluate Ahrefs Batch Analysis against your quality rules.

1

Create a project

Each project keeps its own database and requirements. Use separate projects for separate workflows, sites, or clients.

2

Add a database — or skip it

A database is optional. If you upload one, choose both required columns:

  • Domain — the site/domain column.
  • Status — any status column, regardless of its exact name.
3

Set your quality rules

Enable only the checks you actually need:

  • Minimum Domain Rating (DR).
  • Minimum organic traffic.
  • Minimum referring domains (RD).
  • RD ≥ LD.
  • Allowed top countries.
4

Run a check

With a database, you can paste almost any messy text and Easy will extract domains automatically. For metric checks, upload an Ahrefs Batch Analysis CSV.

Using Ahrefs Batch Analysis

Export your Batch Analysis as CSV and upload it in the checker. Easy detects supported Ahrefs columns automatically. The validation box shows which columns were found. If an enabled rule needs a missing column, the result becomes Cannot evaluate instead of incorrectly failing the domain.

Understanding the results

Passed

The domain satisfies every enabled rule that can be evaluated.

Failed

The domain failed at least one enabled quality rule. The exact reasons appear in the Result column.

Cannot evaluate

An enabled rule needs a metric that is missing from the uploaded Ahrefs CSV.

Database status

In Database + Metrics mode, Easy also shows the exact status from your database. Different statuses for the same domain are preserved rather than silently overwritten.

Filtering and exporting

Use the result tabs, status dropdown, search, and sortable columns to narrow the table. Copy domains copies only the currently filtered domains. Export CSV downloads only the currently filtered results.

Data & privacy

Projects, settings and prospect databases stay in your browser. Account, plan and usage information are stored securely in Easy's account system. Clearing this browser's site data can remove locally stored projects and databases.
